🔧 Solusi:
Saya perlu refactor Netlify function untuk support multi-tenant. Ini task yang cukup kompleks. 


Fastify Multi-Tenant Flow:
• Request comes in with X-Tenant-Id header (or subdomain/path)
• tenantMiddleware extracts tenant identifier and validates it
• Middleware sets request.tenantId and request.tenantSlug
• Route handler calls getTenantAuth(tenantId) to get tenant-specific auth instance
• Auth factory uses tenantManager.getClient(tenantId) to get tenant-specific Prisma client
• Prisma client uses ?schema=tenant_xxx in connection URL
• All data goes to correct tenant schema
Key parts I need in Netlify function:
• Initialize tenant manager (call tenantManager.initialize())
• Extract tenant identifier from request (same logic as middleware)
• Resolve tenant and validate it
• Get tenant-specific auth instance via getTenantAuth(tenantId)
• Handle both admin auth (no tenant) and tenant auth

The tricky part is:
• Netlify functions are stateless, so I need to ensure tenant manager is initialized on cold starts
• I need to handle tenant extraction similar to middleware
• I need to keep admin auth separate (no tenant required)
